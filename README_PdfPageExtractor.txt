PDFページ抽出・考古学資料対応ツール (PDF Page Extractor for Archaeology)
取扱説明書 / README.txt
======================================================================

本書は「PDFページ抽出・考古学資料対応ツール」の機能、仕様、操作方法、および取り扱い上の注意点を説明するマニュアルです。


----------------------------------------------------------------------
1. 概要（Overview）
----------------------------------------------------------------------
■ ツールの目的
発掘調査報告書や学術論文、各種図面・資料等の大容量PDFファイルから、必要なページを解像度・ベクターデータ・縮尺精度を維持したまま切り出し、自動OCRによるページ番号検出と柔軟なファイル名管理を行うための単一HTML型Webアプリケーションです。

■ 解決する課題
・数百ページに及ぶ厚い発掘調査報告書から特定の遺物図面や観察表のみを別ファイルとして抽出する際、画像化による解像度劣化やCADデータのベクター損失を防ぎます。
・PDF内部の物理論理ページ番号と、実際の報告書フッターに印刷されている「版面ページ番号（例: p.105）」の乖離を手動で確認・リネームする作業コストを大幅に削減します。
・外部クラウドへアップロードできない未公表の調査資料や機密文書に対しても、ブラウザ内部処理による完全ローカル・セキュリティ環境を提供します。

■ 開発背景・特徴
・完全ローカル処理（Client-side Security）: ブラウザのメモリ（ArrayBuffer）上で読み込み・描画・OCR・PDF再構築・ZIP作成までをすべて自己完結。外部サーバーへのネットワーク送信は一切行われません。
・無劣化（Lossless）PDF切出: pdf-lib ライブラリを用いてPDFエレメント（ベクター図面、テキストフォント、高解像度画像）を一切再圧縮せず直接抽出・複製します。
・多言語インターフェース対応 (i18n): 日本語・英語・中国語（簡体字）・韓国語・フランス語・スペイン語の全6言語切り替えに対応。国籍を問わず共同研究・調査現場で導入可能です。


----------------------------------------------------------------------
2. 主な機能（Features）
----------------------------------------------------------------------
1. PDF読み込み＆自動サムネイル生成
   - PDF.js を活用し、全ページの軽量サムネイル画像を非同期描画。
   - レンダリング時のメモリリークや Buffer detached を防ぐ堅牢なメモリ管理。

2. フッター領域自動OCR（ページ番号抽出）
   - 各ページの最下部（20%領域）を自動トリミングし、Tesseract.js による光学文字認識（OCR）を実行。
   - フッターに印刷された数字（実ページ数）を自動検出し、初期ファイル名（例: `[元ファイル名]_p[検出番号]`）として提案。

3. カード型ビジュアル選択＆ファイル名即時編集
   - サムネイルカードをクリックするだけの直感的なページ選択/選択解除。
   - OCR検出結果や初期ファイル名を各カード内のテキスト入力欄から個別に手動書き換え可能。

4. 無劣化PDF再構築＆ZIP一括エクスポート
   - 選択されたページを個別PDFに分離保存。
   - 選択が1ページの場合は単一PDFを直接ダウンロード。複数ページの場合は JSZip により圧縮ZIP形式（`[元ファイル名]_extracted.zip`）でまとめて出力。

3. 動作環境（Prerequisites）
----------------------------------------------------------------------
■ 対応OS
  - Windows 10 / 11
  - macOS
  - Linux
  - ChromeOS、iPadOS、Android等の標準Webブラウザ搭載環境

■ 実行環境（Webブラウザ）
  HTML5, ES6, Web Workers, Canvas APIに対応したモダンWebブラウザの最新版を推奨します。
  - Google Chrome
  - Microsoft Edge
  - Mozilla Firefox
  - Apple Safari

■ プログラミング言語・必須ライブラリ
  - インストールが必要なサーバー・プログラミング言語環境（Python, Node.js等）は一切不要です。
  - 外部CDN依存（※インターネット接続時に各種スクリプトをロード）:
    * PDF.js v3.11.174 (PDF描画・レンダリング)
    * pdf-lib v1.17.1 (PDFの結合・抽出・無劣化編集)
    * Tesseract.js v4.1.1 (ブラウザ内OCR機能)
    * JSZip v3.10.1 (ブラウザ内ZIP圧縮処理)
  - オフライン環境で利用する場合は、上記JSライブラリ群をダウンロードし同一ディレクトリの相対パス指定に変更することで完全スタンドアロン動作が可能です。

4. セットアップ・インストール手順（Installation）
----------------------------------------------------------------------
1. 配布または作成された `index.html` （または該当するHTMLファイル）をPCのローカルストレージに保存します。
2. 保存した `.html` ファイルをダブルクリック、または起動中の対応Webブラウザに直接ドラッグ＆ドロップして開いてください。
3. アプリケーションが起動し、ヘッダーおよびファイル選択画面が表示されたらセットアップ完了です。


----------------------------------------------------------------------
5. 使い方（Usage）
----------------------------------------------------------------------
【基本操作フロー】

ステップ 1: 表示言語の選択（任意）
  ・画面右上の言語ドロップダウン（`日本語`, `English`, `中文`, `한국어`, `Français`, `Español`）から使用言語を選択します。

ステップ 2: 報告書PDFファイルの選択
  ・「報告書PDFファイルを選択」エリアのファイル選択ボタンをクリックし、対象のPDFファイルを選択します。

ステップ 3: サムネイル生成とOCR実行の確認
  ・PDFが自動解析され、各ページのサムネイルカード生成とフッターOCRが実行されます。「処理中...」のメッセージが消えるまでお待ちください。

ステップ 4: 抽出ページの選択およびファイル名調整
  ・抽出したいページのサムネイルカードをクリックして選択します（選択中のカードは緑色の枠線に変わります）。
  ・カード下部の入力フォームで、自動生成されたファイル名を必要に応じて直接書き換えます。

ステップ 5: 抽出・保存の実行
  ・「抽出・保存実行」ボタンをクリックします。
  ・単一ページの場合は `.pdf` ファイルが直接保存され、複数ページの場合は `[元ファイル名]_extracted.zip` としてまとめてダウンロードされます。


----------------------------------------------------------------------
6. 入力データの仕様（Input Data Format）
----------------------------------------------------------------------
■ 対応ファイル形式
  - PDFファイル (`.pdf`)
    * PDF 1.3〜1.7、PDF/X、PDF/A 等の規格に対応。
    * スキャン画像中心のPDF、テキスト・フォント情報を含むPDF、CAD由来のベクターデータを含むPDFなど幅広く受け入れ可能。

■ 推奨データレイアウト
  - 発掘調査報告書や論文等の標準的な縦型判型（A4, B5, A3等）。
  - 各ページのフッター（下部20%範囲）に判読可能なページ番号が記載されていると、OCR自動検出の精度が向上します。


----------------------------------------------------------------------
7. 出力・解析結果の見方（Output）
----------------------------------------------------------------------
■ 単一ページ抽出時
  - 形式: 単一PDFファイル (`.pdf`)
  - ファイル名: 入力・編集した指定ファイル名（例: `○○遺跡報告書_p105.pdf`）
  - 特徴: 元PDFのベクター描画精度、拡大縮尺、フォント埋め込み状態が100%保持されます。

■ 複数ページ抽出時
  - 形式: ZIPアーカイブ形式 (`.zip`)
  - ファイル名命名例: `[元ファイル名]_extracted.zip`
  - 内容: 設定したファイル名がそれぞれ付与された無劣化抽出PDF群。

8. トラブルシューティング・留意点（Troubleshooting & Notes）
----------------------------------------------------------------------
■ エラー・不具合時の対処法
  Q1. 巨大なPDFを読み込むと動作が重くなる / ブラウザがクラッシュする
    → 原因: 数百MBを超える大容量ファイルや大量のページを一括読み込みしたことによるメモリ不足（RAM圧迫）。
    → 対処法: ブラウザの他タブを閉じ、最新版のGoogle ChromeやMicrosoft Edge環境で実行してください。

  Q2. フッターのページ番号が正しく検出されない
    → 原因: フッターにノイズが多い、フォントが特殊、またはヘッダー・本文中の数字が拾われた可能性があります。
    → 対処法: サムネイルカード下の入力欄で手動にて書き換えてください。ファイル抽出処理自体には影響しません。

■ セキュリティおよびデータの取り扱い
  - 本ツールで処理されるPDFデータ、解析画像、OCR抽出テキストはすべて端末のブラウザ（メモリ上）でのみ処理されます。
  - 外部サーバーへの通信やデータ送信は一切行われないため、未公表資料や機密文書の処理にも安全にご利用いただけます。
