======================================================================
方眼紙図面特化 超軽量・高精細プレビューツール
取扱説明書 / README.txt
======================================================================

本書は「方眼紙図面特化 超軽量・高精細プレビューツール」の機能、仕様、操作方法、および取り扱い上の注意点を説明するマニュアルです。


----------------------------------------------------------------------
1. 概要（Overview）
----------------------------------------------------------------------
■ ツールの目的
手描きの方眼紙図面、発掘調査図面、建築・測量スケッチ、各種方眼入り画像をWebブラウザ上で読み込み、方眼の4点指定によって歪み・回転・縮尺を正確に補正・標準化し、実寸法（mm/cm）を保持した高精細PDFファイルとしてエクスポートするための単一HTML型軽量Webツールです。

■ 解決する課題
・スキャン時やカメラ撮影時に生じる「台形歪み」「斜め傾き」「レンズ歪み」によって、図面の方眼ピッチが不揃いになる問題を解消します。
・一般的な画像編集ソフトでは煩雑な「実寸あわせ（キャリブレーション）」や「DPIに基づくピクセル計算」を、4点クリックと数値入力のみで自動実行します。
・未公表の測量図面や学術調査資料を外部サーバーに送信することなく、完全ローカル（クライアントサイド）で安全かつ超軽量に処理します。

■ 開発背景・特徴
・完全ブラウザ完結型（完全オフライン・安全設計）: 読み込んだ画像データやPDFは一切サーバーへ送信されず、ブラウザのメモリ内（HTML5 Canvas）でのみ処理されます。
・虫眼鏡（Magnifier）による精密ピッキング: 座標指定時にマウスカーソル位置を円形拡大（3倍）＆赤色十字ポインターで表示し、微小な方眼交点を高精度に指定可能です。
・実寸法同期型5cmメッシュレイヤー: 補正後の原点位置と連動する5cm格子線を表示し、図面全体の歪み抜けやグリッドの一致度を一目で視覚検証できます。


----------------------------------------------------------------------
2. 主な機能（Features）
----------------------------------------------------------------------
1. 多規格対応ファイル読み込み
   - 画像ファイル（PNG, JPEG, WebP等）、PDF文書（PDF.js使用）、TIFF画像（UTIF.js使用）をそのまま読み込み可能。
   - 複数ファイルを順次読み込んで切り替える簡易ファイルリスト機能を搭載。

2. 拡大鏡付き 4点グリッドキャリブレーション
   - 図面上の基準方眼の4交点（①基準点 → ②右 → ③右下 → ④下）をクリック指定。
   - 画面右下に追従する拡大鏡ポインターにより、1ピクセル単位で正確な交点選択が可能。

3. 実寸法（cm）＆目標DPIに基づく自動スケール・台形補正
   - 指定した方眼の実寸法（横幅・高さ cm）と目標解像度（DPI）に基づき、ピクセル数を再計算して高精細補正を実行。

4. 原点同期型 5cmメッシュレイヤー ＆ 微小回転調整
   - 指定した「基準点」を原点（0,0）として、指定DPIに基づいた実寸法5cm間隔の赤色補助線レイヤーを重ね合わせ表示。
   - 0.05度単位の微小回転入力フォームにより、傾きの微妙なズレをリアルタイム追従補正。

5. 印刷スケール保持 PDFエクスポート
   - 補正結果を物理寸法（mm）を正しく保持したPDFとしてエクスポート（jsPDF使用）。1:1のスケールで即座に印刷・図面出力が可能。

6. プレビュー倍率（ズーム）制御 ＆ メモリ解放
   - 5%〜200%の自由な拡大縮小プレビュー表示。
   - 大容量画像を解放しメモリ消費をリセットする初期化ボタンを搭載。

3. 動作環境（Prerequisites）
----------------------------------------------------------------------
■ 対応OS
  - Windows 10 / 11
  - macOS
  - Linux
  - ChromeOS、iPadOS、Android等の標準Webブラウザ搭載環境

■ 実行環境（Webブラウザ）
  HTML5 Canvas, ES6, Web Workers, Blob APIに対応したモダンWebブラウザの最新版。
  - Google Chrome（推奨）
  - Microsoft Edge（推奨）
  - Mozilla Firefox
  - Apple Safari

■ プログラミング言語・必須ライブラリ
  - インストールが必要なサーバー環境（Python, Node.js等）は一切不要です。
  - 外部CDN依存（※インターネット接続時に自動ロード）:
    * PDF.js v3.11.174 (PDFファイルのレンダリング)
    * UTIF.js v3.1.0 (TIFF画像のデコード)
    * jsPDF v2.5.1 (PDF生成・保存)
  - オフライン環境で運用する場合は、上記JSライブラリを事前にローカル保存し、HTML内の `<script src="...">` パスを変更してください。

4. セットアップ・インストール手順（Installation）
----------------------------------------------------------------------
1. 配布された `index.html` （または該当するHTMLファイル）をPCのローカルストレージに保存します。
2. 保存した `.html` ファイルをダブルクリックするか、起動している対応Webブラウザにドラッグ＆ドロップして開いてください。
3. アプリケーション画面（左側操作パネル、右側図面キャンバス）が表示されれば準備完了です。

5. 使い方（Usage）
----------------------------------------------------------------------
【基本操作フロー】

ステップ 1: 図面ファイルの読み込み
  ・左パネル「1. 図面読み込み」の「ファイルを選択」ボタンをクリックし、対象の画像・PDF・TIFFファイルを選択します（複数選択可）。
  ・読み込まれたファイルは「ファイルリスト」に表示され、クリックで切り替えができます。

ステップ 2: プレビュー表示倍率の調整
  ・「0. プレビュー表示倍率」スライダーを操作し、見やすい大きさに表示倍率（5%〜200%）を変更します。

ステップ 3: 基準方眼の 4点指定
  ・「2. 基準方眼の『4点』を指定」グループの「① 4点指定を開始・リセット」ボタンをクリックします。
  ・画面右下の「拡大鏡（Magnifier）」を確認しながら、図面中の方眼格子線上で以下の順番に4点（正方形または長方形の枠）をクリックします。
    1点目: 基準点（左上交点）
    2点目: 右側の交点
    3点目: 右下の交点
    4点目: 下側の交点
  ※途中でやり直したい場合は右クリックで中断できます。

ステップ 4: 実寸法の入力および歪み補正の実行
  ・「3. 実寸法と解像度」欄にて、指定した4点枠の「横幅の実寸法 (cm)」と「高さの実寸法 (cm)」を入力します。
  ・「スキャン想定解像度 (DPI)」を指定します（標準: 300 DPI）。
  ・「② 台形歪み・全体補正を実行」ボタンをクリックします。

ステップ 5: メッシュ確認と微小回転調整（任意）
  ・「4. 5cmメッシュレイヤー」の「メッシュ: ON」ボタンを押すと、基準点を原点とした5cm間隔のグリッドが表示されます。
  ・図面全体の傾きをさらに細かく調整したい場合、「微小回転角度 (度)」に数値（例: 0.15 または -0.1）を入力して微調整します。

ステップ 6: 結果の保存
  ・「5. 結果の保存とメモリ解放」の「PDFで保存」ボタンをクリックします。
  ・補正された高精細図面が、実寸法（mm）に基づくPDF形式でダウンロードされます。


----------------------------------------------------------------------
6. 入力データの仕様（Input Data Format）
----------------------------------------------------------------------
■ 対応ファイル形式
  - 画像ファイル: `.png`, `.jpg`, `.jpeg`, `.webp`, `.bmp`
  - PDFファイル: `.pdf` （先頭10ページまで読み込み対応）
  - TIFFファイル: `.tif`, `.tiff` （シングルページ/マルチページデコード）

■ 推奨データ仕様・制限
  - ファイルサイズ制限: 1ファイルあたり 100MB 以下を推奨（メモリ溢れ防止のため）。
  - 推奨条件: 方眼（1cm格子、5mm格子など）の交点が視認できる解像度であること。


----------------------------------------------------------------------
7. 出力・解析結果の見方（Output）
----------------------------------------------------------------------
■ 保存ファイル仕様
  - 出力フォーマット: PDFファイル (`.pdf`)
  - 標準ファイル名: `corrected_drawing_[幅px]x[高さpx].pdf`
  - 特徴: 設定したDPI値と指定実寸法（cm）に基づき、PDFの用紙サイズ（mm）が動的設定されます。CADソフトやPDFビューアで開いた際、実寸縮尺（1:1）を完全に維持して印刷・計測可能です。

8. トラブルシューティング・留意点（Troubleshooting & Notes）
----------------------------------------------------------------------
■ エラー・不具合時の対処法
  Q1. ファイル読み込み時に「PDF解析失敗」エラーが出力される
    → 原因: パスワード保護されたPDF、破損したPDF、またはローカルブラウザのセキュリティ制限（Web Worker不可）の可能性があります。
    → 対処法: PDFの保護を解除するか、一旦画像形式（PNG/JPEG）に変換してから読み込んでください。

  Q2. 補正実行時にブラウザの動作が著しく重くなる / フリーズする
    → 原因: 極めて巨大な画像（10,000px以上など）に対し高DPI（600DPI〜1200DPI）を指定したことによるCanvasメモリ圧迫。
    → 対処法: 目標DPIを「300DPI」程度に設定し直すか、「補正解除して初期化」ボタンを押してメモリを解放してください。

  Q3. 拡大鏡（Magnifier）が表示されない
    → 原因: キャンバス外にマウスがある、または画像が読み込まれていません。
    → 対処法: 画像領域内にマウスカーソルを移動させてください。

■ セキュリティおよびデータの取り扱い
  - 本ツールに入力された図面データは、すべてユーザー端末のブラウザ内部メモリ（JavaScript Canvas API）でのみ処理されます。
  - 外部ネットワークへの画像送信やクラウド保存は一切行われません。未公表の発掘調査資料や企業・機関の機密図面も安心してご利用いただけます。
