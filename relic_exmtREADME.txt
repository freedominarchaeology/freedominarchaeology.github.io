取扱説明書 / README.txt

本書は「考古学報告書 遺物個別抽出・PDF縮尺出力ツール」の機能、セットアップ方法、および操作手順を説明する取扱説明書です。


----------------------------------------------------------------------
1. 概要（Overview）
----------------------------------------------------------------------
■ ツールの目的
考古学報告書（PDFまたはデジタル画像）に掲載された複数の遺物図面から、目的の遺物領域を個別抽出・切り出し、任意の指定縮尺（実寸1/1や1/6、1/10など）に正確にサイズ変換してPDF・画像・ベクターデータ（EPS）として保存・再利用するためのツールです。

■ 解決する課題
・報告書のPDFから遺物を1点ずつ手動で切り出して縮尺合わせを行う煩雑な作業の自動化・効率化。
・異なる掲載縮尺で作成された図面を、統一した目的縮尺（例：すべて1/6や1/2）で整列・比較出力。
・トレース作業や図録作成に便利なシルエット（影絵）および中心線骨格線画（EPS）の自動生成。

■ 特徴
・完全ローカル処理：読み込んだファイルや処理データが外部サーバーへ送信されることはありません。セキュリティ面・機密面でも安心してご利用いただけます。
・多言語対応：日本語、英語、中国語、韓国語、フランス語、スペイン語のUI切替に対応しています。


----------------------------------------------------------------------
2. 主な機能（Features）
----------------------------------------------------------------------
1. ファイル読み込み & スケール自動検出
   - PDF（複数ページ可）および画像ファイル（PNG, JPEG等）に対応。
   - PDF内の縮尺テキスト表記（例: "1/6", "1/4" 等）を自動検出して提示。
   - スケールバー測距モード：図中のスケールバーの両端をクリックすることで実数値から掲載縮尺を逆算算出。

2. マニュアル範囲指定切り出し
   - プレビュー画面上でマウスをドラッグするだけで、抽出したい遺物領域を直感的に複数指定可能（指定順に番号・タイトルを自動割り振りに反映）。

3. 目的縮尺への自動スケーリング出力
   - 原本の掲載縮尺（例: 1/6）と出力希望縮尺（例: 1/1実寸、1/2、1/10など）を指定するだけで、自動で正確な印刷寸法（mm換算）へスケーリング調整。

4. 画像処理・シルエット/ベクトル変換機能
   - トリミングの微調整（範囲設定・座標直接指定）。
   - しきい値（スライダー）調整によるリアルタイム・シルエット（２値化）生成。
   - 中心線ストローク（骨格線）およびシルエットのベクターデータ（EPS形式）出力。

5. 形状類似度による自動並び替え（ソート）
   - 抽出した複数の遺物画像を数学的（形状特徴量）に解析し、類似する形状ごとに自動並び替え。

6. ZIP一括パッケージ出力
   - 抽出・生成した各種フォーマット（PDF / JPG / EPS）を整理されたフォルダ構成でまとめてZIPダウンロード。

5. 使い方・操作フロー（Usage）
----------------------------------------------------------------------
【基本操作ステップ】

ステップ 1: ファイルを選択する
  ・「1. ファイル選択」ボタンから、報告書のPDFまたは図面画像を選択します。
  ・必要に応じて「2. 出力ファイル名の接頭辞」にファイル名の頭に付ける文字列（例: siteA_trench1）を入力します。

ステップ 2: 基準掲載縮尺（原本）と出力希望縮尺を設定する
  ・「3. 基準掲載縮尺」：元の図面がどの縮尺で描かれているかを選択します（例: 1/6）。
    - PDF内から自動検出された候補がある場合は、青色の候補バッジ（例: [1/6]）をクリックして一括適用できます。
    - 図中にスケールバーがある場合は「📐 図中スケールバーから算出」を選択し、実寸(cm)を入力した上でスケールバーの両端を2回クリックすることで精密に自動算出されます。
  ・「4. 出力希望縮尺」：出力したいターゲット縮尺を選択します（例: 1/1 実寸法、1/2 等）。

ステップ 3: 低性能PC向け設定（必要に応じて）
  ・「5. 処理モード」：メモリ使用量を抑えたい場合や動作を軽快にしたい場合は「軽量 (低メモリ・高速)」を選択してください。

ステップ 4: プレビュー画面で抽出範囲を指定する
  ・画面中部のプレビューエリアで、切り出したい遺物の周りをマウスでドラッグして囲みます。
  ・ドラッグした順に①, ②, ③…と番号が割り当てられます。
  ・指定をやり直したい場合は「指定範囲を全クリア」を押します。

ステップ 5: 取り込みと解析を実行する
  ・「指定範囲を取り込んで抽出・解析実行」ボタンをクリックします。
  ・画面下部に抽出された遺物カードが一覧表示されます。

ステップ 6: 微調整・結果確認
  ・各カード内でタイトル（図番号）の変更、トリミング範囲の再調整、シルエット濃さ（スライダー）の微調整を行えます。
  ・必要に応じて「形状類似度で並び替え」ボタンで似た形状をまとめられます。

ステップ 7: ダウンロード
  ・各カードの個別出力ボタン（PDF / JPG / EPS）を押すか、チェックボックスで選択した上で「選択した X 件のPDF・JPG・EPSを一括ZIPダウンロード」をクリックします。


----------------------------------------------------------------------
6. 入力データの仕様（Input Data Format）
----------------------------------------------------------------------
■ 対応入力ファイル形式
  - PDFドキュメント (.pdf) ※複数ページ可
  - 各種画像フォーマット (.png, .jpg, .jpeg, .webp, .bmp 等)

■ 推奨データ構造・解像度
  - スケールバー（10cm, 5cm等）や縮尺表記（1/6 等）が明確に記載された図面データ。
  - 切り出し範囲内に目的の遺物全体が収まっていること。
  - 図面線が極端に薄くないデータ（鮮明な白黒またはグレースケール図面を推奨）。


----------------------------------------------------------------------
7. 出力・解析結果の見方（Output）
----------------------------------------------------------------------
ZIP一括ダウンロードを実行すると、以下のように整理されたフォルダ構造で各種ファイルが出力されます。

【出力フォルダ構成】
  └ [設定した接頭辞]_extracted_artifacts_bundle.zip
      ├─ 1_Raw_PDF/        : 切り出した原本解像度のPDF
      ├─ 2_Raw_JPG/        : 切り出した原本解像度のJPG画像
      ├─ 3_Scaled_PDF/     : 指定希望縮尺に正確スケーリング調整されたPDF
      ├─ 4_Scaled_JPG/     : 指定希望縮尺にスケーリング調整された高解像度JPG画像
      ├─ 5_Silhouette_PDF/ : ２値化シルエットのPDF
      ├─ 6_Silhouette_JPG/ : ２値化シルエットのJPG画像
      ├─ 7_Silhouette_EPS/ : シルエットのアウトライン・ベクターデータ (EPS)
      └─ 8_Skeleton_EPS/   : 細線化（骨格抽出）処理による線画ベクターデータ (EPS)

■ カード画面の表示情報
  - ピクセルサイズ : 抽出された領域の横×縦のピクセル解像度
  - 出力スケール比率 : 原本から目的縮尺への倍率（例: 1.000）
  - 紙面サイズ幅 : 目的縮尺でPDF印刷・配置した際の実寸ミリメートル（mm）幅

8. トラブルシューティング・留意点（Troubleshooting & Notes）
----------------------------------------------------------------------
■ トラブルシューティング
  Q1. 巨大なPDFを読み込むと動作が重くなる・ブラウザがフリーズする
    → 対処法：「5. 処理モード」を「軽量 (低メモリ・高速 4.0)」に変更してから読み込んでください。

  Q2. シルエット（影絵）にノイズが入る、または正しく黒く潰れない
    → 対処法：各カード内にある「濃さ調整」スライダーを左右に動かして、適切な２値化しきい値に調整してください。

  Q3. EPSファイルをIllustrator等で開くと拡大/縮小されている
    → 対処法：EPSファイルにはBoundingBox情報（HiResBoundingBox）が含まれており、指定したスケール情報に基づいています。リンク配置または実寸読み込み（100%）で使用してください。

■ データ取り扱い上の注意
  - 本ツールで処理されるデータは、すべてお使いのPCのブラウザメモリ内でのみ処理されます。外部サーバーへの自動アップロード等は一切行われません。
  - ブラウザをリロード（再読み込み）したり閉じたりすると、読み込んだデータや抽出設定は消去されますので、必要な成果物は必ずダウンロードしてから終了してください。
