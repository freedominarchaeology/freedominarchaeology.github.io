======================================================================
考古学図面 Excel自動貼り付けツール（Archaeological Drawing Excel Auto-Placer）
取扱説明書 / README.txt
======================================================================

本書は「考古学図面 Excel自動貼り付けツール」の機能、仕様、操作方法、および取り扱い上の注意点を説明するマニュアルです。


----------------------------------------------------------------------
1. 概要（Overview）
----------------------------------------------------------------------
■ ツールの目的
発掘調査報告書や遺物整理で準備された多数の図面画像（JPEG）と、その説明テキストをまとめ、Excel（.xlsx）形式の整理表・一覧表として自動生成・一括出力するブラウザベースの軽量ツールです。

■ 解決する課題
・大量の図面画像を1枚ずつExcelシートに手動で挿入・リサイズ・位置合わせする作業の膨大な手間の解消。
・画像挿入時にセルからはみ出したり、行高や列幅の調整が不揃いになる問題の自動解消。
・外部ライブラリや専用サーバーを介さない単一ファイル構成により、インターネット接続が制限された現場やセキュリティ規定の厳しい研究環境でも即座に導入可能。

■ 開発背景・特徴
・完全ローカル・オフライン処理：読み込んだ画像データや入力テキストは外部サーバーへ送信されず、お使いのPC（ブラウザ上）のみで完結します。機密資料の取り扱いにも安心です。
・外部ライブラリ非依存（Pure JavaScript）：オープンソースのOpenXML構造生成（MiniZip）を内蔵しており、Node.jsやPython、あるいはExcel本体が未インストールでも動作します。
・多言語対応（i18n）：日本語、英語、中国語（簡体字）、スペイン語のUI表示に対応しており、ブラウザ言語の自動検出および手動切り替えが可能です。


----------------------------------------------------------------------
2. 主な機能（Features）
----------------------------------------------------------------------
1. ドラッグ＆ドロップによる画像一括読み込み
   - JPEG形式（.jpg, .jpeg）の図面画像を複数まとめて簡単に読み込み可能。

2. プレビュー & メタデータ表示
   - 読み込んだ図面のサムネイル画像、ファイル名、およびオリジナル画像解像度（幅×高さ px）を一覧表示。

3. 画像ごとの説明文（テキスト）入力
   - 各図面に対応する説明文（遺物番号、出土遺構、注記等）を自由に入力・編集可能（改行対応）。

4. A列セル内自動収容スケーリング
   - Excel出力時、A列のセル内に画像が綺麗に収まるよう縦横比を維持したまま自動リサイズ（セル高150pt、幅30単位設定）。

5. OpenXML直接生成による高速Excel (.xlsx) 書き出し
   - サードパーティ製ライブラリを介さず、軽量Zip処理によって標準のExcelワークブック (.xlsx) を生成。

6. リアルタイム状態管理 & 簡易操作
   - 個別画像の削除、および全項目の一括クリア機能。
   - 言語切り替え時のUIおよび出力デフォルトファイル名の即時更新。

----------------------------------------------------------------------
■ OS
  - Windows 10 / 11

  - Linux
  - ChromeOS 等（HTML5/ES6対応環境全般）

  - Microsoft Edge
  - Mozilla Firefox
  - Apple Safari

■ 必要なプログラミング言語・外部ソフト

  - Excelソフト本体がインストールされていないPCでも、.xlsxファイルの作成が可能です。

4. セットアップ・インストール手順（Installation）
----------------------------------------------------------------------
1. 提供された `index.html`（または本ツールが記述されたHTMLファイル）をPCの任意のフォルダに保存します。
2. 保存したHTMLファイルをダブルクリック、あるいは起動中のWebブラウザにドラッグ＆ドロップして開いてください。
3. インストール作業やネットワーク経由の通信、ビルド処理等は不要で、開いた直後から即座にご利用いただけます。

5. 使い方（Usage）
----------------------------------------------------------------------
【基本操作フロー】

ステップ 1: 言語を選択する（必要に応じて）
  ・画面右上の「🌐」ドロップダウンメニューから表示言語（日本語 / English / 简体中文 / Español）を選択します。
  ・※初期状態ではお使いのブラウザ言語が自動で選択されます。

ステップ 2: JPEG図面画像を読み込む
  ・中央の破線領域（「ここにJPEG画像をドラッグ＆ドロップ」）へ、対象のJPEGファイルをドロップします。
  ・または破線領域をクリックしてファイル選択ダイアログからファイルを選択します。

ステップ 3: 説明文を入力する
  ・各行の「説明文 (B列入力)」テキストエリアに、該当する図面の説明や注記を入力します。

ステップ 4: リストの調整
  ・個別に削除したい画像がある場合は、操作列の「削除」ボタンをクリックします。
  ・最初からやり直したい場合は「すべて消去」ボタンを押します。

ステップ 5: Excel (.xlsx) ファイルの書き出し
  ・「📊 Excel (.xlsx) 書き出し」ボタンをクリックします。
  ・生成された `.xlsx` ファイル（例: `図面一覧_2026-08-26.xlsx`）がダウンロードされます。


----------------------------------------------------------------------
6. 入力データの仕様（Input Data Format）
----------------------------------------------------------------------
■ 対応ファイル形式
  - JPEG画像（拡張子: `.jpg`, `.jpeg`）

■ 入力テキスト仕様
  - 各画像に対してプレーンテキスト（改行、全角/半角、特殊文字対応）が入力可能。

■ 推奨画像仕様
  - 解像度制限はありませんが、出力時には表示領域（約200×180 px相当）へ収まるように自動計算されます。
  - 大量の高解像度画像を同時に読み込む場合、事前に適正サイズへリサイズしておくと処理速度が向上します。


----------------------------------------------------------------------
7. 出力・解析結果の見方（Output）
----------------------------------------------------------------------
■ 出力ファイルフォーマット
  - Microsoft Excel ワークブック形式（.xlsx）

■ デフォルトファイル名（言語設定に対応）
  - 日本語: `図面一覧_YYYY-MM-DD.xlsx`
  - 英語: `DrawingsList_YYYY-MM-DD.xlsx`
  - 中国語: `图纸列表_YYYY-MM-DD.xlsx`
  - スペイン語: `ListaDeDibujos_YYYY-MM-DD.xlsx`

■ ワークシート（シート名: 「図面一覧」等）の構造
  - 1行目: ヘッダー行（A1セル: 「図面」、B1セル: 「説明文」）
  - A列 (幅: 30): 各JPEG図面画像（縦横比維持、セル高 150pt 内に自動配置）
  - B列 (幅: 60): 各画像に対応する説明文（テキスト折り返し有効、上揃え配置）

8. トラブルシューティング・留意点（Troubleshooting & Notes）
----------------------------------------------------------------------
■ トラブルシューティング
  Q1. ファイルを選択してもリストに追加されない
    → 原因: 選択したファイルがJPEG形式以外（PNG, GIF, PDFなど）の可能性があります。
    → 対処法: 画像形式を `.jpg` または `.jpeg` に変換してから再度読み込んでください。

  Q2. 大量の画像を追加したら画面が重くなった / フリーズした
    → 原因: ブラウザの利用可能メモリ（RAM）上限に達している可能性があります。
    → 対処法: 数十枚ずつ分けてExcel書き出しを行うか、元画像のピクセル解像度を少し下げてから読み込んでください。

  Q3. ダウンロードしたExcelファイルが開けない・壊れていると表示される
    → 対処法: ブラウザをリロードし、再度書き出しを実行してください。また、対応しているExcelバージョン（Excel 2007以降 / LibreOffice / Googleスプレッドシート等）で開いているかご確認ください。

■ データの取り扱い・セキュリティ上の注意
  - 本ツールで処理される画像およびテキストデータは、すべてブラウザの内部メモリ上のみで保持されます。
  - 外部サーバーへの通信やストレージ保存は一切行われないため、ページの再読み込み（リロード）やブラウザの閉鎖を行うと入力中のデータは消去されます。必要な出力結果は必ずダウンロードしてください。
