======================================================================
悪を刺せ - 技奥義版 (Stab the Evil Advanced) 取扱説明書
======================================================================

1. 概要（Overview）
* ツールの目的: 画面上のスワイプ・連打・ジェスチャーコマンドを入力することで多彩な剣技（奥義）を発動し、湧き出る邪悪な赤い棒人間を討伐する2Dジェスチャーアクションゲームです[cite: 22]。
* 解決する課題: 単純な一方向スワイプのみだった操作性に格闘ゲームのようなコマンド入力要素を追加し、ブラウザ上で奥深い駆け引きと派手なエフェクト演出を実現します[cite: 22]。
* 開発背景: リアルタイムな描画軌跡の角度変化累計・反転回数・連打周波数を判定する高度なジェスチャー解析エンジンおよび、無敵時間管理・エフェクトプールの最適化実験として開発されました[cite: 22]。

----------------------------------------------------------------------
2. 主な機能（Features）
----------------------------------------------------------------------
* 高度ジェスチャー解析エンジン:
  - 入力された座標軌跡（pathPoints）の長さ、回転角度、方向転換回数、連打速度をミリ秒単位で解析し、コマンドを自動識別します[cite: 22]。
* 5大奥義・必殺技システム:
  1. 連続突き: 画面を高速連打して周囲を連続攻撃[cite: 22]。
  2. 突進突き: 後ろに引いてから前へスワイプし、超高速で貫通ダッシュ[cite: 22]。
  3. 燕返し: 左右に素早く往復スワイプし、クロス斬撃を発生[cite: 22]。
  4. 唐竹割り: 1回転を描いた後、下方へ大きく切り下ろして画面縦一列を一撃粉砕[cite: 22]。
  5. 八刀一閃: 八方向に素早く切り込む高難易度技で全画面の敵を一網打尽[cite: 22]。
* 無敵時間＆領域ダメージ（広範囲衝撃波）:
  - 各奥義の発動時には一定の無敵時間（invulnerable）が付与され、強力な範囲攻撃が発生します[cite: 22]。
* リアルタイム演出＆技名バナー表示:
  - 技が成功すると画面中央に光る技名バナーがポップアップし、カラフルな斬撃ライン（Slash Effects）が描画されます[cite: 22]。
* 多言語UI対応:
  - 日本語、英語、中国語、韓国語、フランス語、スペイン語の6言語リアルタイム切替に対応[cite: 22]。

----------------------------------------------------------------------
3. 動作環境（Prerequisites）
----------------------------------------------------------------------
* 対応端末: PC / スマートフォン / タブレット（Windows, macOS, iOS, Android, Linux）[cite: 22]
* 推奨ブラウザ: Google Chrome, Safari, Microsoft Edge, Mozilla Firefox 最新版[cite: 22]
* 必須ライブラリ: なし（HTML5 Canvas / CSS3 / ES6+ バニラJavaScriptのみで動作）[cite: 22]
* 必要API: DOM API, Canvas 2D Context API, Touch / Mouse Events API[cite: 22]

----------------------------------------------------------------------
4. セットアップ・インストール手順（Installation）
----------------------------------------------------------------------
1. stabtheevilad.html ファイルを取得・保存します[cite: 22]。
2. Webサーバーやプログラミング環境の構築は不要です[cite: 22]。
3. 保存した stabtheevilad.html ファイルを任意のWebブラウザで直接開きます（ダブルクリックまたはドラッグ＆ドロップ）[cite: 22]。

----------------------------------------------------------------------
5. 使い方（Usage）
----------------------------------------------------------------------
1. 言語選択: 画面右上のドロップダウンメニューから言語を選択します[cite: 22]。
2. ゲーム開始: 「ゲーム開始」ボタンを押します[cite: 22]。
3. 操作＆奥義コマンド入力一覧:
   - 通常移動 / スワイプ: 画面をドラッグ／スワイプして移動[cite: 22]。
   - 連続突き: 600ミリ秒以内に画面を4回以上高速連打（タップ）[cite: 22]。
   - 突進突き: 進行方向とは逆へ一度引き込み、前方向へ一気にスワイプ[cite: 22]。
   - 燕返し: 左右に往復するように素早くジグザグスワイプ[cite: 22]。
   - 唐竹割り: 画面上でくるりと円（1回転）を描き、そのまま下方向へまっすぐスワイプ[cite: 22]。
   - 八刀一閃: 切り返すように8方向へ素早く乱書きスワイプ[cite: 22]。
4. 再挑戦: 敵に触れてゲームオーバーになった後、「再挑戦」ボタンで即時リセット・再スタートが可能です[cite: 22]。

----------------------------------------------------------------------
6. 入力データの仕様（Input Data Format）
----------------------------------------------------------------------
* 操作入力: マウスドラッグ・クリック / タッチスワイプ・タップ（Touch / Mouse Events経由）[cite: 22]。
* 内部ジェスチャーデータ: 入力された座標履歴（最大30ポイント）およびタップタイムスタンプをリアルタイム配列管理[cite: 22]。
* 外部ファイル入力: 不要（画像・音源等の外部アセット不使用）[cite: 22]。

----------------------------------------------------------------------
7. 出力・解析結果の見方（Output）
----------------------------------------------------------------------
* 討伐数（スコア）: 画面左上UIに現在までに撃破した敵の合計数が表示されます[cite: 22]。
* 技バナー（SKILL BANNER）: 奥義成功時に画面中央に技名がポップアップ表示されます[cite: 22]。
* プレイヤー状態表現:
  - 青色: 通常状態[cite: 22]
  - オレンジ色発光: 無敵（インバーナブル）状態[cite: 22]
* 斬撃エフェクト: 発動した奥義に応じた固有カラーの線（紫・青・黄・緑・赤など）が描画されます[cite: 22]。

----------------------------------------------------------------------
8. トラブルシューティング・留意点（Troubleshooting & Notes）
----------------------------------------------------------------------
* 技がうまく出ない場合:
  - 「唐竹割り」は円を描く動作の後にしっかり「下」へ抜けることが必要です[cite: 22]。
  - 「連続突き」は指の押し込み速度（600ms内に4回以上）が重要です[cite: 22]。
* 無敵の切れ目に注意:
  - 各奥義の無敵時間は数十フレーム程度（約0.3〜0.6秒）です[cite: 22]。技が終わった直後に敵の真っ只中に取り残されないよう配置を意識してください[cite: 22]。

11. 操作のコツ・楽しみ方（Tips & Strategy）
----------------------------------------------------------------------
【奥義を使いこなしてハイスコアを目指す極意】
1. 敵に囲まれたら「連続突き」で緊急脱出:
   敵が近づいてきたら画面を素早くトントンと連打するだけで、周囲の敵を一撃で蹴散らし無敵状態に入ることができます[cite: 22]。
2. 遠くの集団には「唐竹割り」または「突進突き」:
   画面上部に敵がたまっている場合は円を描いて下へ切り下ろす「唐竹割り」を発動させると、画面縦一列の敵を一瞬で全滅させられます[cite: 22]。
3. 「無敵時間」を利用した奥義コンボ:
   技発動中のオレンジ色に光っている間は無敵です[cite: 22]。無敵時間が切れる前に次の奥義（例: 連続突きから燕返しへ繋ぐ）を入力することで、安全に連撃を叩き込むことが可能です[cite: 22]。
