======================================================================
Balance Game (バランスゲーム) 改訂版 取扱説明書
======================================================================

1. 概要（Overview）
* ツールの目的: スマートフォンの傾きセンサー（DeviceOrientation）を活用し、時間経過とともに変化するターゲット領域内にボールを維持する体感型Web物理バランスゲームです[cite: 20]。
* 解決する課題: インストール不要でWebブラウザのみで手軽に遊べる点に加え、動的に変化する難易度設計により、短時間でも歯ごたえのある体感ゲーム体験を提供します[cite: 20]。
* 開発背景: DeviceOrientation APIとHTML5 Canvasを組み合わせた物理計算ロジックに、動的な難易度上昇アルゴリズムおよび初心者に優しい猶予期間（Grace Period）を追加した拡張検証として開発されました[cite: 20]。

----------------------------------------------------------------------
2. 主な機能（Features）
----------------------------------------------------------------------
* 傾きセンサー連動物理計算: 端末の傾き（ベータ軸・ガンマ軸）に応じたリアルタイムなボールの加速度・慣性・摩擦力計算[cite: 20]。
* 動的ターゲット領域（縮小＆移動）:
  - ゲーム開始時は従来より広いターゲット円でスタート（画面最小辺の35%）[cite: 20]。
  - 経過時間に応じてターゲット円が徐々に縮小（毎秒2.5px縮小、最小サイズ制限あり）[cite: 20]。
  - スコア10秒経過後、ターゲット円自体がゆらゆらと円運動を開始[cite: 20]。
* 開始直後の猶予期間（Grace Period）: ゲームスタート後1.5秒間は判定が無効化され、スタート時の不意な失敗を防止[cite: 20]。
* 多言語UI対応: 日本語、英語、中国語、韓国語、フランス語、スペイン語の6言語リアルタイム切替[cite: 20]。
* フレームレート独立制御: デルタタイム（dt）駆動の物理・ゲームループにより、端末のフレームレートに依存しない公平な挙動を実現[cite: 20]。

----------------------------------------------------------------------
3. 動作環境（Prerequisites）
----------------------------------------------------------------------
* 対応端末: スマートフォン / タブレット（iOS / Android）[cite: 20]
* 推奨ブラウザ: Safari (iOS), Google Chrome (Android) 最新版[cite: 20]
* 必須ハードウェア: 傾き・ジャイロセンサー[cite: 20]
* 実行環境: HTTPS接続されたWebサーバー（WebセンサーAPI使用の必須セキュリティ条件）[cite: 20]
* 使用技術: HTML5, CSS3, JavaScript (ES6+), Canvas API[cite: 20]

----------------------------------------------------------------------
4. セットアップ・インストール手順（Installation）
----------------------------------------------------------------------
1. balancegame_2.html ファイルを取得します[cite: 20]。
2. HTTPS対応のWebサーバーにアップロードするか、ローカル開発環境（https://localhost等）を準備します[cite: 20]。
3. スマートフォンのWebブラウザで該当URLを開きます[cite: 20]。

----------------------------------------------------------------------
5. 使い方（Usage）
----------------------------------------------------------------------
1. 言語選択: 画面右上のドロップダウンメニューから希望の言語を選択します[cite: 20]。
2. ゲーム開始: 「ゲーム開始」ボタンをタップします[cite: 20]。
3. 権限許可: ブラウザのアクセス許可ダイアログ（モーションと方向）が表示されたら「許可」を選択します[cite: 20]。
4. プレイ: スマートフォンを前後左右に傾け、赤色のボールを緑色のターゲット内に留め続けます[cite: 20]。
   - 最初は広いターゲットですが、時間が経つと小さくなり、10秒を超えるとターゲット自体が移動し始めます[cite: 20]。
5. 再挑戦: ボールがターゲット外や画面外に出るとゲームオーバーになります。「もう一度プレイ」でリスタートします[cite: 20]。

----------------------------------------------------------------------
6. 入力データの仕様（Input Data Format）
----------------------------------------------------------------------
* モーションデータ: DeviceOrientationEvent から取得される beta（前後傾き角度: -90°〜90°）および gamma（左右傾き角度: -90°〜90°）のリアルタイム角度数値[cite: 20]。

----------------------------------------------------------------------
7. 出力・解析結果の見方（Output）
----------------------------------------------------------------------
* リアルタイムスコア（プレイ中画面左上）: ターゲット内にボールを維持できている生存時間（秒）[cite: 20]。
* 結果カード（ゲームオーバー時）: 最終生存スコア（秒）が表示されます[cite: 20]。

----------------------------------------------------------------------
8. トラブルシューティング・留意点（Troubleshooting & Notes）
----------------------------------------------------------------------
* 「Sensor error」またはボールが動かない場合:
  - HTTP（非暗号化通信）では動作しません。必ず https:// 環境でアクセスしてください[cite: 20]。
  - iOSの場合は「設定」>「Safari」>「モーションと方向のアクセス」が有効になっているか確認してください。
* スタート直後にボールが流れてしまう場合:
  - 開始1.5秒間は猶予期間（Grace Period）となっているため、その間にスマートフォンを水平に整えて姿勢を安定させてください[cite: 20]。

11. 操作のコツ・楽しみ方（Tips & Strategy）
----------------------------------------------------------------------
【高記録（10秒以上の壁突破）を狙うテクニック】
1. 1.5秒の猶予期間でゼロ点を合わせる:
   スタート直後の1.5秒間はボールがターゲット外に出てもゲームオーバーになりません[cite: 20]。この隙にスマホの保持角度とボールの勢いを完全にリセットしましょう[cite: 20]。
2. 前半（0〜10秒）: ターゲット中央での「静止」を最優先:
   前半はエリアが広いため、傾けすぎず最小限の微修正でボールの速度（慣性）を完全に殺しておくことが後半への準備となります[cite: 20]。
3. 後半（10秒〜）: ターゲットの円運動に「波乗り」する:
   10秒を超えるとターゲットがゆらゆら動き出します[cite: 20]。ターゲットの動きを追いかけるのではなく、ターゲットが揺れ動くリズムに合わせてスマホをわずかに傾け、ボールをゆっくり追従させる「振り子感覚」でコントロールするのがコツです[cite: 20]。
