======================================================================
Balance Game (バランスゲーム) 取扱説明書
======================================================================

1. 概要（Overview）
* ツールの目的: スマートフォンの傾きセンサー（DeviceOrientation）を活用し、ボールを中央のターゲット円内に維持する体感型Web物理バランスゲームです[cite: 18]。
* 解決する課題: アプリの事前インストールなしで、Webブラウザのみで直感的に遊べる物理バランスゲームを提供します[cite: 18]。
* 開発背景: DeviceOrientation APIおよびHTML5 Canvasを利用した、軽量かつフレームレート依存のない物理挙動ロジックの実証として開発されました[cite: 18]。

----------------------------------------------------------------------
2. 主な機能（Features）
----------------------------------------------------------------------
* 傾きセンサー連動物理計算: スマートフォンの傾き（ベータ軸・ガンマ軸）に応じたリアルタイムなボールの加速度・摩擦力計算[cite: 18]。
* 多言語UI対応: 日本語、英語、中国語、韓国語、フランス語、スペイン語の6言語に対応し、即座に表示切替が可能[cite: 18]。
* レスポンシブCanvas描画: 端末の画面サイズに合わせてターゲット円やボールのサイズを自動調整[cite: 18]。
* フレームレート独立制御: デルタタイム（dt）を用いた物理計算により、端末性能に左右されない一定のゲームスピードを実現[cite: 18]。

----------------------------------------------------------------------
3. 動作環境（Prerequisites）
----------------------------------------------------------------------
* 対応端末: スマートフォン / タブレット（iOS / Android）[cite: 18]
* 推奨ブラウザ: Safari (iOS), Google Chrome (Android) 最新版[cite: 18]
* 必須ハードウェア: 傾き・ジャイロセンサー[cite: 18]
* 実行環境: HTTPS接続されたWebサーバー（センサーAPI使用の必須条件）[cite: 18]
* 使用技術: HTML5, CSS3, JavaScript (ES6+), Canvas API[cite: 18]

----------------------------------------------------------------------
4. セットアップ・インストール手順（Installation）
----------------------------------------------------------------------
1. balancegame.html ファイルを取得します[cite: 18]。
2. HTTPS対応のWebサーバーにアップロードするか、ローカル開発環境（https://localhost等）を準備します[cite: 18]。
3. スマートフォンのWebブラウザで該当URLを開きます[cite: 18]。

----------------------------------------------------------------------
5. 使い方（Usage）
----------------------------------------------------------------------
1. 言語選択: 画面右上のドロップダウンメニューから言語を選択します[cite: 18]。
2. ゲーム開始: 「ゲーム開始」ボタンをタップします[cite: 18]。
3. 権限許可: ブラウザのアクセス許可ダイアログが表示されたら「許可」を選択します[cite: 18]。
4. プレイ: スマートフォンを前後左右に傾け、赤色のボールを中央の緑色のターゲット円の中に留め続けます[cite: 18]。
5. 再挑戦: ボールがターゲット外や画面外に出るとゲームオーバーになります。「もう一度プレイ」でリスタートします[cite: 18]。

----------------------------------------------------------------------
6. 入力データの仕様（Input Data Format）
----------------------------------------------------------------------
* モーションデータ: DeviceOrientationEvent から取得される beta（前後傾き角度: -90°〜90°）および gamma（左右傾き角度: -90°〜90°）の数値データ[cite: 18]。

----------------------------------------------------------------------
7. 出力・解析結果の見方（Output）
----------------------------------------------------------------------
* リアルタイムスコア（プレイ中画面左上）: ターゲット内にボールを維持できている経過時間（秒）[cite: 18]。
* 結果カード（ゲームオーバー時）: 最終生存スコア（秒）が表示されます[cite: 18]。

----------------------------------------------------------------------
8. トラブルシューティング・留意点（Troubleshooting & Notes）
----------------------------------------------------------------------
* 「Sensor error」またはボールが動かない場合:
  - HTTP（非暗号化通信）でアクセスしていないか確認してください。HTTPS環境が必須です[cite: 18]。
  - iOSの場合は「設定」>「Safari」>「モーションと方向のアクセス」が許可されているか確認してください[cite: 18]。
* ボールが急激に跳ね飛ぶ場合:
  - ゲーム開始時はスマートフォンを床と水平に保持した状態で「ゲーム開始」ボタンを押してください[cite: 18]。

11. 操作のコツ・楽しみ方（Tips & Strategy）
----------------------------------------------------------------------
【高記録を狙うための操作のコツ】
1. 水平スタートの徹底:
   ゲーム開始の瞬間、スマートフォンを地面と完全に平行に保つことで、スタート直後の不意の滑り出しを防ぎます[cite: 18]。
2. 最小限の傾きで制御:
   ボールには慣性が働きます。大きく傾けると加速しすぎて制御不能になるため、わずかに傾けて反対側にゆっくり戻す「微修正」を心がけましょう[cite: 18]。
3. 円の中心ではなく「速度ゼロ」を目指す:
   ボールを中心に戻すことよりも、速度（勢い）を殺してターゲット内で静止させる意識を持つと安定します[cite: 18]。
