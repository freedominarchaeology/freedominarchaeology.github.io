======================================================================
Rhythm Game (リズムゲーム) 取扱説明書
======================================================================

1. 概要（Overview）
* ツールの目的: Webブラウザ上で動作し、画面タップとマイク音声入力を組み合わせて遊ぶ新感覚リズムアクションゲームです[cite: 19]。
* 解決する課題: アプリの事前インストールなしで、通常のタップ操作に加えて「声」をトリガーにした体感型ゲーム体験を提供します[cite: 19]。
* 開発背景: Web Audio API および MediaDevices API (getUserMedia) を活用し、単一HTMLファイルのみでリアルタイム音声解析と効果音合成を行う技術検証として開発されました[cite: 19]。

----------------------------------------------------------------------
2. 主な機能（Features）
----------------------------------------------------------------------
* ハイブリッド判定システム: 青色ノーツ（タップ判定）と黄色ノーツ（マイク音声入力判定）の2種類の入力処理[cite: 19]。
* リアルタイム音声合成: 外部音声ファイルを使わず、Web Audio APIでオシレーターから直接効果音を生成・再生[cite: 19]。
* 多言語対応UI: 日本語、英語、中国語、韓国語、フランス語、スペイン語の6言語に対応し、即時切替が可能[cite: 19]。
* オブジェクトプーリング実装: ノーツ要素の再利用（notePool）により、ガベージコレクションに伴う処理落ちを防ぎ高いパフォーマンスを維持[cite: 19]。

----------------------------------------------------------------------
3. 動作環境（Prerequisites）
----------------------------------------------------------------------
* 対応端末: PC / スマートフォン / タブレット（Windows, macOS, iOS, Android）[cite: 19]
* 推奨ブラウザ: Google Chrome, Safari, Microsoft Edge, Mozilla Firefox 最新版[cite: 19]
* 必須ハードウェア: マイク（VOICEノーツ入力用）[cite: 19]
* 実行環境: HTTPS接続されたWebサーバー（マイクAPI使用の必須セキュリティ要件）[cite: 19]
* 使用技術: HTML5, CSS3, JavaScript (ES6+), Web Audio API, Canvas API, MediaDevices API[cite: 19]

----------------------------------------------------------------------
4. セットアップ・インストール手順（Installation）
----------------------------------------------------------------------
1. rhythmgame.html ファイルを取得します[cite: 19]。
2. HTTPS対応のWebサーバーにアップロードするか、ローカル開発環境（https://localhost 等）を用意します[cite: 19]。
3. ブラウザで該当ファイル（またはURL）にアクセスします[cite: 19]。

----------------------------------------------------------------------
5. 使い方（Usage）
----------------------------------------------------------------------
1. 言語選択: 画面右上のドロップダウンメニューで言語を選択します[cite: 19]。
2. ゲーム開始: 「スタート」ボタンをタップ／クリックします[cite: 19]。
3. マイク権限の許可: ブラウザのポップアップに従い「マイクの利用」を許可します（無効時はタップで代替可能）[cite: 19]。
4. プレイ方法:
   - 青色ノーツ: 緑色の判定線に重ねて画面をタップ／クリック[cite: 19]。
   - 黄色ノーツ（VOICE）: 判定線に重なったタイミングでマイクに向かって声を出します[cite: 19]。
5. 再挑戦: リザルト画面で「再挑戦」ボタンを押すと再プレイできます[cite: 19]。

----------------------------------------------------------------------
6. 入力データの仕様（Input Data Format）
----------------------------------------------------------------------
* 音声入力: MediaStream (オーディオアナライザー経由のリアルタイム音量・周波数データ)[cite: 19]。
* タップ／クリック入力: TouchEvent / MouseEvent の画面座標およびタイミング[cite: 19]。
* 譜面データ（内部データ）: songData 配列（構造: { time: 秒数, lane: レーン(0~2), type: 'tap'|'voice' }）[cite: 19]。

----------------------------------------------------------------------
7. 出力・解析結果の見方（Output）
----------------------------------------------------------------------
* スコア（Score）: PERFECT(+100)、GREAT(+50)、VOICE OK(+150) の評価に応じて加算[cite: 19]。
* コンボ（Combo）: 連続成功数。MISSで0にリセット[cite: 19]。
* 判定表示: 判定線上に「PERFECT!」「GREAT」「MISS」「VOICE OK!」をリアルタイム描画[cite: 19]。
* 終了画面: 最終獲得スコアを表示[cite: 19]。

----------------------------------------------------------------------
8. トラブルシューティング・留意点（Troubleshooting & Notes）
----------------------------------------------------------------------
* マイクが反応しない・「マイク無効」と表示される場合:
  - 非暗号化通信（http://）ではアクセスできません。必ず https:// 環境で実行してください[cite: 19]。
  - ブラウザのサイト設定でマイクアクセスが許可されているか確認してください[cite: 19]。
  - マイクが無効でもタップ操作で判定を代替できます[cite: 19]。
* 音が鳴らない場合:
  - 画面を1回タップ／クリックしてブラウザの音声自動再生制限（Autoplay Policy）を解除してください[cite: 19]。

11. 操作のコツ・楽しみ方（Tips & Strategy）
----------------------------------------------------------------------
【ハイスコア獲得のコツ】
1. VOICEノーツは「少し早め」に発声:
   マイク判定の音量閾値検出にわずかなタイムラグがあるため、ノーツが緑色の線に到達する直前に声を出し始めると安定します[cite: 19]。
2. 短く鋭い声（「ハッ！」「ハイ！」）を意識:
   長引かないハッキリした声を出すことで、次のタップノーツへの対応がスムーズになります[cite: 19]。
3. 声が出せない時は「手拍子」で代替:
   マイクは一定以上の音量を感知するため、手拍子や机を叩く音でも反応させることができます[cite: 19]。
