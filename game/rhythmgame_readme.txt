======================================================================
Beat Pulse Rhythm (ビートパルス リズム) 改訂版 取扱説明書
======================================================================

1. 概要（Overview）
* ツールの目的: Webブラウザ上で動作し、重厚なキックドラムのビートに合わせて画面タップとマイク音声（VOICE）入力を組み合わせて遊ぶ体感型リズムアクションゲームです[cite: 22]。
* 解決する課題: アプリの事前インストールなしで、通常のタップ操作に加えて「声」をトリガーにした臨場感あるリズム体験を提供します[cite: 22, 23]。
* 開発背景: Web Audio APIによるリアルタイム・ドラムオシレーター合成とMediaDevices APIによる音声解析を統合し、Canvas上で円形リングが収束する軽量リズムエンジンの改訂検証として開発されました[cite: 22]。

----------------------------------------------------------------------
2. 主な機能（Features）
----------------------------------------------------------------------
* 3パッド＆リング収束システム: 画面下部の3つのパッド（左・中央・右）に向かって外側からリングが収束するビジュアル演出[cite: 22]。
* ハイブリッド入力判定: 左右パッドのタップ判定に加え、中央の「VOICE」パッドでのマイク音声（またはタップ）判定に対応[cite: 22]。
* Web Audioリアルタイムドラム合成: 低音キック（アタック音付き）とハイハットのサウンドをコード制御で動的に合成・再生[cite: 22]。
* 空振り・判定厳格化: ノーツのないタイミングでの連打・空振りタップをMISSと判定し、コンボがリセットされるアーケード仕様のロジック[cite: 22]。
* 多言語UI対応: 日本語、英語、中国語、韓国語、フランス語、スペイン語の6言語リアルタイム切替[cite: 22]。

----------------------------------------------------------------------
3. 動作環境（Prerequisites）
----------------------------------------------------------------------
* 対応端末: PC / スマートフォン / タブレット（Windows, macOS, iOS, Android）[cite: 22, 23]
* 推奨ブラウザ: Google Chrome, Safari, Microsoft Edge, Mozilla Firefox 最新版[cite: 22, 23]
* 必須ハードウェア: マイク（VOICE入力機能使用時）[cite: 22, 23]
* 実行環境: HTTPS接続されたWebサーバー（マイクAPIおよびWeb Audio機能の必須セキュリティ要件）[cite: 22, 23]
* 使用技術: HTML5, CSS3, JavaScript (ES6+), Web Audio API, Canvas API, MediaDevices API[cite: 22]

----------------------------------------------------------------------
4. セットアップ・インストール手順（Installation）
----------------------------------------------------------------------
1. rhythmgame_2.html ファイルを取得します[cite: 22]。
2. HTTPS対応のWebサーバーにアップロードするか、ローカル開発環境（https://localhost 等）を用意します[cite: 22, 23]。
3. スマートフォンやPCのWebブラウザで該当URL（またはファイル）を開きます[cite: 22, 23]。

----------------------------------------------------------------------
5. 使い方（Usage）
----------------------------------------------------------------------
1. 言語選択: 画面右上のドロップダウンメニューで表示言語を選択します[cite: 22]。
2. ゲーム開始: 「スタート」ボタンをタップ／クリックします（Web Audioとマイク解析が初期化されます）[cite: 22]。
3. マイク権限の許可: ブラウザのアクセス許可ダイアログが表示されたら「許可」を選択します（無効時はタップ操作で代替）[cite: 22]。
4. プレイ方法:
   - 重厚なキックドラムのビートに合わせ、リングが下部のパッドに重なる瞬間に該当エリアをタップします[cite: 22]。
   - 中央の「VOICE」パッドは、リングが重なった瞬間にマイクに向かって声を出すことでも反応します[cite: 22]。
5. 再挑戦: ステージクリア後、オーバーレイ画面の「再挑戦」ボタンでリスタートできます[cite: 22]。

----------------------------------------------------------------------
6. 入力データの仕様（Input Data Format）
----------------------------------------------------------------------
* 音声入力: MediaStream (オーディオアナライザーによる周波数データの平均音量算出、音量閾値38超で判定トリガー)[cite: 22]。
* タップ／クリック入力: TouchEvent / MouseEvent（Canvas内の3つのパッド半径エリアに基づく判定）[cite: 22]。
* 内部譜面データ（beats配列）: { time: 発声/打撃タイミング(秒), padIndex: パッド位置(0~2), type: 'tap'|'voice' }[cite: 22]。

----------------------------------------------------------------------
7. 出力・解析結果の見方（Output）
----------------------------------------------------------------------
* スコア（Score）: PERFECT(+100)、GREAT(+50)、VOICE OK(+150) の評価に応じて加算[cite: 22]。
* コンボ（Combo）: 連続成功数。MISS（タイミングずれ・空振りタップ）で0にリセット[cite: 22]。
* 判定表示: パッド上部に「PERFECT!」「GREAT」「MISS!」「VOICE OK!」をリアルタイム描画[cite: 22]。
* 終了画面: ステージクリア時に最終獲得スコアを表示[cite: 22]。

----------------------------------------------------------------------
8. トラブルシューティング・留意点（Troubleshooting & Notes）
----------------------------------------------------------------------
* マイクが反応しない・「マイク無効」と表示される場合:
  - 非暗号化通信（http://）では動作しません。必ず https:// 環境でアクセスしてください[cite: 22, 23]。
  - ブラウザのサイト設定でマイク権限が許可されているか確認してください[cite: 22, 23]。
  - マイクが無効な状態でも、中央パッドをタップすることでプレイ可能です[cite: 22, 23]。
* 音が鳴らない場合:
  - 画面上の「スタート」ボタンを押すことでブラウザの自動再生制限（Autoplay Policy）が解除されます[cite: 22, 23]。
  - スマホの消音モード（マナーモード）が有効になっていないか確認してください。

11. 操作のコツ・楽しみ方（Tips & Strategy）
----------------------------------------------------------------------
【ハイスコア・高コンボ獲得のコツ】
1. 重厚な「キック音」のビートを感じる:
   本ゲームはBPM120のキックドラムの音と完全に同期しています。耳で低音のドラムリズムを取りながら、リングの収束を目で確認するとジャストタイミング（PERFECT）が狙いやすくなります[cite: 22]。
2. VOICEノーツは短く鋭い声（「ハッ！」「オイ！」）を意識:
   声の音量解析は閾値判定を行っているため、長く伸ばす声よりも短くハッキリとした発声をする方が瞬時に検知され高得点（VOICE OK: +150）を獲得しやすくなります[cite: 22]。
3. 空振りタップ（連打）は厳禁:
   ノーツが来ていないタイミングで画面をタップするとMISS判定となり、コンボがリセットされてしまいます。リングがパッドに重なる瞬間までぐっと引きつけてから1回だけ正確にタップしましょう[cite: 22]。
