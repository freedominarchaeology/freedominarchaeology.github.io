======================================================================
Ghost Wizard AR (ゴーストウィザード AR) 取扱説明書
======================================================================

1. 概要（Overview）
* ツールの目的: スマートフォンの各種センサーを活用し、現実空間に出現するゴーストをレーダーで追跡・撃退する体感型ARアクションWebゲームです[cite: 17]。
* 解決する課題: 画面内のボタン操作にとどまらない、身体動作（端末を振る・突く・回す・方向を向く）と連動した没入感のある体感ゲーム体験を、アプリのインストールなし（Webブラウザのみ）で実現します[cite: 17]。
* 開発背景: Web API（DeviceMotion / DeviceOrientation / Geolocation / Web Audio）の技術検証および、単一HTMLファイルで手軽に遊べるAR体感ゲームとして開発されました[cite: 17]。

----------------------------------------------------------------------
2. 主な機能（Features）
----------------------------------------------------------------------
* ジャイロ・加速度センサー連動コマンド: 端末を振る方向（8方向の斬撃）、押し出す（突き）、手前に引く（引き寄せ）、体を一巡させる（回転斬り）動作をリアルタイムで識別・魔法発動[cite: 17]。
* GPS & 方位レーダー: 端末の電子コンパスおよび位置情報をもとに、ゴーストとの相対方角・距離をCanvas上に視覚化[cite: 17]。
* 近接サウンドフィードバック: 敵との距離に応じてピッチと間隔が変化するソナー（ビープ音）再生機能[cite: 17]。
* コンボ＆倍率システム: 2.5秒以内に連続攻撃を成功させることでダメージ倍率が上昇[cite: 17]。
* ローカルランキング: スコアおよびプレイヤー名をブラウザ内保存（localStorage）[cite: 17]。
* 多言語対応: 日本語および英語の切り替え機能[cite: 17]。

----------------------------------------------------------------------
3. 動作環境（Prerequisites）
----------------------------------------------------------------------
* 対応端末: スマートフォン / タブレット（iOS / Android）[cite: 17]
* 推奨ブラウザ: Safari (iOS), Google Chrome (Android) 最新版[cite: 17]
* 必須ハードウェア: 加速度センサー、ジャイロセンサー、GPS機能（位置情報）[cite: 17]
* 通信環境・プロトコル: HTTPS接続必須（WebセンサーAPIのセキュリティ制約のため）[cite: 17]
* 使用技術: HTML5, CSS3, JavaScript (ES6+), Web Audio API, Canvas API[cite: 17]

----------------------------------------------------------------------
4. セットアップ・インストール手順（Installation）
----------------------------------------------------------------------
1. 本パッケージから ghost_wizard_ar.html を取得します[cite: 17]。
2. HTTPS対応のWebサーバーにアップロードするか、ローカル開発環境（例: VS Code Live Server、https://localhost 等）を起動します[cite: 17]。
3. スマートフォンのWebブラウザで該当URLにアクセスします[cite: 17]。

----------------------------------------------------------------------
5. 使い方（Usage）
----------------------------------------------------------------------
1. 名前を入力: 画面上部の入力欄にプレイヤー名を入力します（任意）[cite: 17]。
2. 探知スタート: 「探知スタート」ボタンをタップします[cite: 17]。
3. 権限の許可: ブラウザから要求される「モーションと方向へのアクセス」および「位置情報の利用」を「許可」に設定します[cite: 17]。
4. 索敵: 音声ビープとレーダー画面を確認し、端末の向きを調整してゴースト（赤点）の方向に体を向けます[cite: 17]。
5. 攻撃: ゴーストを正面に捉えた状態で、端末を振る・突くなどのアクションを行い、魔法を発動させてHPを削ります[cite: 17]。
6. リセット: ゲームを最初からやり直す場合は「リセット」ボタンを押し、データをクリアします[cite: 17]。

----------------------------------------------------------------------
6. 入力データの仕様（Input Data Format）
----------------------------------------------------------------------
* プレイヤー名: テキスト（最大10文字 / 任意）- ランキング登録用名称[cite: 17]
* モーションデータ: DeviceMotionEvent（必須）- 端末の三軸加速度（dx, dy, dz）による技判定[cite: 17]
* 方位データ: DeviceOrientationEvent（必須）- 端末の向き（コンパス方位角）[cite: 17]
* 位置情報: Geolocation Lat/Lng（必須）- 敵のスポーン位置計算に使用[cite: 17]

----------------------------------------------------------------------
7. 出力・解析結果の見方（Output）
----------------------------------------------------------------------
* ステータスパネル: スコア、ゴーストHP、現在方位角、推定距離（m）を表示[cite: 17]。
* レーダー描画: 中央から伸びる扇状の視界エリアと、敵の相対位置（赤丸）を表示[cite: 17]。
* 戦闘ログ: 発動した魔法の技名、コンボ数、与えたダメージ、撃破ログをリアルタイム表示[cite: 17]。
* ベストスコア: 上位10位までのスコアを表示（localStorage に保存）[cite: 17]。

----------------------------------------------------------------------
8. トラブルシューティング・留意点（Troubleshooting & Notes）
----------------------------------------------------------------------
* 「センサーアクセスが拒否されました」と表示される場合:
  - iOSでは画面タップによる許可が必要です。「探知スタート」ボタン後のポップアップで許可を選択してください[cite: 17]。
  - Safari設定で「モーションと方向のアクセス」がオンになっているか確認してください。
* センサーが作動しない場合:
  - HTTP通信では動作しません。必ず https:// 環境で実行してください[cite: 17]。
* レーダーの方角がずれる場合:
  - スマートフォンを持ったまま空気中で8の字を描くように動かし、電子コンパスを校正してください。

11. 操作のコツ・楽しみ方（Tips & Strategy）
----------------------------------------------------------------------
【魔法コマンド一覧】
* 唐竹割り（上から下）: 【破魔炎】高威力攻撃[cite: 17]
* 斬上げ（下から上）: 【昇天雷】打ち上げ攻撃[cite: 17]
* 右/左薙ぎ（横スイング）: 【氷結陣】/【影縫い】属性攻撃[cite: 17]
* 突き（奥へ押し出す）: 【伏龍破】単体大ダメージ[cite: 17]
* 引き（手前に引く）: 【霊力引き寄せ】敵との距離を約8m短縮[cite: 17]
* 回転（360度まわる）: 【旋風円舞】全方位即死級範囲攻撃[cite: 17]

【ハイスコア獲得のテクニック】
1. 引き寄せで間合いを詰めて索敵音の精度と戦闘効率を最大化[cite: 17]。
2. 2.5秒以内に連続攻撃を行いコンボ倍率（x1.35〜）を重ねる[cite: 17]。
3. 向きを見失った際は1回転して「旋風円舞」を発動させる[cite: 17]。
