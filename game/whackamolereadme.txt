======================================================================
もぐらたたき / Whack-a-Mole 取扱説明書
======================================================================

1. 概要（Overview）
* ツールの目的: Webブラウザ上で動作する3D風立体ステージ仕様の直感的な「もぐらたたき」ゲームです[cite: 20]。
* 解決する課題: アプリの事前インストールや外部ライブラリの読み込みを必要とせず、PC・スマートフォン・タブレット等のあらゆる環境で手軽に反射神経を鍛える体感型ゲームを提供します[cite: 20]。
* 開発背景: CSS3の3Dトランスフォーム（perspective / rotateX）を活用した立体視効果と、JavaScriptのメモリ再利用（ガベージコレクション抑制）アルゴリズムを検証するために開発されました[cite: 20]。

----------------------------------------------------------------------
2. 主な機能（Features）
----------------------------------------------------------------------
* 3Dパースペクティブステージ: 3×3（計9個）の穴が斜め3D視点で配置されたアーケード風デザイン[cite: 20]。
* 動的ランダム出現システム: 直前に出現した穴や出現中の穴を避けるスマートな出現制御アルゴリズム[cite: 20]。
* 制限時間＆リアルタイムスコア: 30秒の制限時間内に叩いたもぐらの数（1匹につき10点）をリアルタイム計算[cite: 20]。
* イベント委譲＆タッチ最適化: pointerdownイベントによる低延滞なタップ反応と連打対策・二重カウント防止機能[cite: 20]。
* 多言語UI対応: 日本語、英語、中国語、韓国語、フランス語、スペイン語の6言語リアルタイム切替[cite: 20]。

----------------------------------------------------------------------
3. 動作環境（Prerequisites）
----------------------------------------------------------------------
* 対応端末: PC / スマートフォン / タブレット（Windows, macOS, iOS, Android）[cite: 20]
* 推奨ブラウザ: Google Chrome, Safari, Microsoft Edge, Mozilla Firefox 最新版[cite: 20]
* 必須ライブラリ: なし（HTML5 / CSS3 / ES6+ バニラJavaScriptのみで動作）[cite: 20]
* 必要API: DOM API, Pointer Events API[cite: 20]

----------------------------------------------------------------------
4. セットアップ・インストール手順（Installation）
----------------------------------------------------------------------
1. whackamole.html ファイルを取得・保存します[cite: 20]。
2. Webサーバー等の構築は不要です[cite: 20]。
3. 保存した whackamole.html ファイルを任意のWebブラウザで直接開きます（ダブルクリックまたはドラッグ＆ドロップ）[cite: 20]。

----------------------------------------------------------------------
5. 使い方（Usage）
----------------------------------------------------------------------
1. 言語選択: 画面右上のドロップダウンメニューで表示言語を選択します[cite: 20]。
2. ゲーム開始: 画面下部の「スタート」ボタンをクリック／タップします[cite: 20]。
3. プレイ方法:
   - 穴から顔を出した「もぐら」を制限時間（30秒）以内に素早くクリック／タップします[cite: 20]。
   - 1匹叩くごとに「スコア」が10点加算されます[cite: 20]。
4. 再挑戦: タイムアップ（ゲーム終了）後、アラートを閉じ、「再挑戦」ボタンでリセットして再スタートできます[cite: 20]。

----------------------------------------------------------------------
6. 入力データの仕様（Input Data Format）
----------------------------------------------------------------------
* 操作入力: マウスクリック / タッチタップ / ポインター入力（PointerEvent）[cite: 20]。
* 外部ファイル入力: 不要（画像や音声などの外部アセットは不使用、CSSでデザイン生成）[cite: 20]。

----------------------------------------------------------------------
7. 出力・解析結果の見方（Output）
----------------------------------------------------------------------
* スコア（Score）: 現在獲得している得点（1匹＝10点）[cite: 20]。
* 残り時間（Time）: ゲームの残り時間（30秒からカウントダウン）[cite: 20]。
* 終了ダイアログ: 制限時間終了時に最終獲得スコアがポップアップアラートで表示されます[cite: 20]。

----------------------------------------------------------------------
8. トラブルシューティング・留意点（Troubleshooting & Notes）
----------------------------------------------------------------------
* タップが反応しない／ずれる場合:
  - 穴ではなく、もぐら本体（茶色のキャラクター領域）を正しくクリック／タップしてください[cite: 20]。
* 連打してもスコアが増えない場合:
  - もぐらは1度の出現につき1回しかカウントされない二重ヒット防止仕様となっています[cite: 20]。

11. 操作のコツ・楽しみ方（Tips & Strategy）
----------------------------------------------------------------------
【ハイスコア（300点超え）を獲得するテクニック】
1. スマートフォン／タブレットでは両手の指を使う:
   タッチパネル端末でプレイする場合、両手の親指や人差し指を構えておくことで、出現と同時に最速でタップできます[cite: 20]。
2. 画面全体（3×3グリッド）の中央に視点を置く:
   特定の1つの穴を凝視するのではなく、盤面全体を視野に入れておくことで、周辺視野でもぐらの動きを捉えやすくなります[cite: 20]。
3. 頭が出始めた瞬間を狙う:
   もぐらは出現してから約0.6〜1.1秒で引っ込みます。引っ込み始める前、頭が見えた瞬間に反応するのがパーフェクト達成の秘訣です[cite: 20]。
