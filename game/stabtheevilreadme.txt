======================================================================
悪を刺せ - Stab the Evil 取扱説明書
======================================================================

1. 概要（Overview）
* ツールの目的: 画面をスワイプ／ドラッグして線を描き、青い棒人間を突進（ダッシュ）させて邪悪な赤い棒人間を刺して撃破する2Dアクションゲームです[cite: 21]。
* 解決する課題: アプリのインストールや外部ライブラリの読み込みを一切不要とし、ブラウザ一つで直感的なスワイプ操作とスピード感あるアクション体験を提供します[cite: 21]。
* 開発背景: スワイプの長さと角度に基づくベクトル物理演算および、オブジェクトプールを活用した低負荷・高フレームレートのCanvas描画処理の実証実験として開発されました[cite: 21]。

----------------------------------------------------------------------
2. 主な機能（Features）
----------------------------------------------------------------------
* ベクトルスワイプ＆突進物理演算:
  - ドラッグ／スワイプした線の方向と長さに応じて、キャラクターの突進方向と速度（パワー）がリアルタイムに変化します[cite: 21]。
* 判定切り替え型アクション（ダッシュシステム）:
  - 突進中（ダッシュ状態）のみ敵を刺して撃破でき、減速して通常状態になると敵との接触でゲームオーバーになります[cite: 21]。
* スコア連動型敵AI＆スポーン制御:
  - 討伐数（スコア）の増加に伴い、敵の移動速度が上昇しスポーン数が増加します[cite: 21]。
* メモリ最適化（オブジェクトプール）:
  - 最大12体の敵オブジェクトをあらかじめ生成・再利用（MAX_ENEMIES = 12）し、ガベージコレクションによるカクつき（スタッター）を抑止します[cite: 21]。
* 多言語UI対応:
  - 日本語、英語、中国語、韓国語、フランス語、スペイン語の6言語リアルタイム切替に対応[cite: 21]。

----------------------------------------------------------------------
3. 動作環境（Prerequisites）
----------------------------------------------------------------------
* 対応端末: PC / スマートフォン / タブレット（Windows, macOS, iOS, Android, Linux）[cite: 21]
* 推奨ブラウザ: Google Chrome, Safari, Microsoft Edge, Mozilla Firefox 最新版[cite: 21]
* 必須ライブラリ: なし（HTML5 Canvas / CSS3 / ES6+ バニラJavaScriptのみで動作）[cite: 21]
* 必要API: DOM API, Canvas 2D Context API, Touch / Mouse Events API[cite: 21]

----------------------------------------------------------------------
4. セットアップ・インストール手順（Installation）
----------------------------------------------------------------------
1. stabtheevil.html ファイルを取得・保存します[cite: 21]。
2. Webサーバーやプログラミング環境の構築は不要です[cite: 21]。
3. 保存した stabtheevil.html ファイルを任意のWebブラウザで直接開きます（ダブルクリックまたはドラッグ＆ドロップ）[cite: 21]。

----------------------------------------------------------------------
5. 使い方（Usage）
----------------------------------------------------------------------
1. 言語選択: 画面右上のドロップダウンメニューから希望の言語を選択します[cite: 21]。
2. ゲーム開始: 中央の「ゲーム開始」ボタンを押します[cite: 21]。
3. 基本操作:
   - 画面上をマウスでドラッグ、または指でスワイプして黄色のベクター線を描きます[cite: 21]。
   - 指／マウスを離すと、線の反対方向ではなく「線を描いた方向」へ青い棒人間が勢いよく突進します[cite: 21]。
4. 撃破と回避:
   - 突進（ダッシュ）中に赤い棒人間へ体当たりすることで刺して撃破できます[cite: 21]。
   - 速度が落ちてダッシュが解除された状態で敵に触れるとゲームオーバーになります[cite: 21]。
5. 再挑戦: ゲームオーバー画面の「再挑戦」ボタンで即座にリセット・再スタートできます[cite: 21]。

----------------------------------------------------------------------
6. 入力データの仕様（Input Data Format）
----------------------------------------------------------------------
* 操作入力: マウスクリック・ドラッグ / タッチスワイプ操作（Touch / Mouse Events経由）[cite: 21]。
* 外部ファイル入力: 不要（画像・音源等の外部アセットは使用せずCanvas描画のみで完結）[cite: 21]。

----------------------------------------------------------------------
7. 出力・解析結果の見方（Output）
----------------------------------------------------------------------
* 討伐数（スコア）: 画面左上UIに現在までに撃破した敵の合計数がリアルタイム表示されます[cite: 21]。
* 画面表示:
  - 黄色の線: スワイプ中の狙い（ベクトルの方向とパワー）[cite: 21]
  - 青色の棒人間: プレイヤー[cite: 21]
  - 赤色の棒人間: 敵キャラクター[cite: 21]
* 結果画面: ゲームオーバー時に総討伐数がオーバーレイ画面で表示されます[cite: 21]。

----------------------------------------------------------------------
8. トラブルシューティング・留意点（Troubleshooting & Notes）
----------------------------------------------------------------------
* 減速時の接触判定に注意:
  - プレイヤーの速度は毎フレーム摩擦（× 0.95）で衰退します[cite: 21]。速度が一定（0.8）以下になるとダッシュ状態が解除され、敵を刺せなくなります[cite: 21]。
* モバイル操作時のスクロール防止:
  - タッチ操作時には標準の画面スクロールを防ぐ処理（e.preventDefault()）が組み込まれています[cite: 21]。

11. 操作のコツ・楽しみ方（Tips & Strategy）
----------------------------------------------------------------------
【高記録（ハイスコア）を叩き出す攻略法】
1. 長いスワイプで最高速度を出す:
   スワイプ距離が長いほど突進速度（パワー）が上がり、より遠くまでダッシュ状態を維持できます[cite: 21]。
2. 一つの突進で複数の敵を連続撃破（一網打尽）:
   敵が密集している場所へ向けて長距離の突進を繰り出すことで、1回のスワイプで複数の敵を安全に連続討伐できます[cite: 21]。
3. 壁際の追い詰められに注意する:
   外周の壁に当たると速度が停止します[cite: 21]。ステージ中央を維持するように移動方向をコントロールすることが生き残る秘訣です[cite: 21]。
